## Project Statement


# Project title
Person to Person Parking System

# Problem statement 

Drivers may spend time searching for parking while nearby residents or property owners may have unused spaces. This project demonstrates a simple way for an owner to list a space and for another person to find,book, and cancel a reservation through command line program.

## Scope

The project is a local , single process educational prototype. It supports sampe data,parking-space listings, hourly bookings totals, booking history for a typed in name and a cancellation.It does not include real accounts, identify verification,online payements or permanent storage.

## Target Users 

- Space Owners: people who want to offer an available parking space.
- Drivers:people who want to browse and reserve space.

## Objectives

- Apply functions loops,conditions,listand dictionaries to practical problem.
- Divide small program to clear modules.
- Validate user input and update space availability consistently when bookings are made or cancelled .
- Explain the design with a workflow , component view , UML-style diagrams and a project report
